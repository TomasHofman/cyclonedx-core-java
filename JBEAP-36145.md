## Reproduction Steps

Described on https://redhat.atlassian.net/browse/JBEAP-36145.

## Verification Notes

Rebuilding projects:
* Rebuild this branch of cyclonedx.
* Update cyclonedx version in galleon-plugins.
* Rebuild galleon plugins.

Preparing "patch repo":
* Deploy galleon plugins to local repository: ` mvn deploy -DaltDeploymentRepository=deploy-repo::default::file:path/to/test-repo/`
* Deploy manifest file with upgraded galleon-plugins versions (to the snapshot that was build in previous steps).

Testing the upgrade (using Update 9 repo + the "patch repo"):
* Start with JBoss EAP 8.1 Update 7.1 or Update 8.
* `./standalone.sh`
* `./jboss-cli.sh -c`

Upgrade with Update 9 repo only should fail:
* `installer update --confirm --repositories=file:jboss-eap-8.1.9.GA-runtime-maven-repository/maven-repository/`

Upgrade with Update 9 repo + patch repo should succeed:
* `installer update --confirm --repositories=file:jboss-eap-8.1.9.GA-runtime-maven-repository/maven-repository/,file:path/to/test-repo/`
